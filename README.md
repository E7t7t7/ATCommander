# AT Commander 1.7.26

Run on Windows with:

**Double-click `AT Commander.exe` in the extracted folder.** It opens the dark desktop app without a command window. On first use it prepares the Python environment through a setup window. Python 3.10+ with Tkinter must be installed. Existing credentials and settings are reused.

**Update Commander** at the top of the app downloads updates from [your GitHub repository](https://github.com/E7t7t7/ATCommander). After it reports ready, close Commander normally once active work finishes, then reopen the EXE to install. Downloads are pinned to one commit and verified against its public-file manifest. Updates preserve account data, preferences, research queues and the local browser profile; replacements are backed up and failed/interrupted installs roll back. The button does not interrupt running battles or start game actions. It is separate from the game-client compatibility check below. See `GITHUB_UPDATES.md` for publishing future builds.

The extracted `ATCommander_1.7.26` folder is the current source of truth. It continues the functional 1.7.25 source derived from the extracted 1.7.23 folder. All older change notes remain included. See `README_1.7.26_CHANGES.md`, `COMMAND_REFERENCE.md` and `BENDER_PARITY.md` for changes, commands and remaining verification gaps.

**Check / update game client** is now at the top of the app. It checks the official public release and automatically installs a compatible client profile. New builds are inspected offline for matching request-signing, version and Unity helper structures, with literal/type/method bindings checked; downloaded game code is never executed. Version 1.183.0 is verified and included. A changed signing scheme or unsupported engine remains paused rather than being accepted from its version number alone. The check is cancellable and starts no game action.

The dark interface now uses a charcoal/teal palette, clearer Daily play / Battles / Collection / More navigation, a visible selected page, softer activity panels and sentence-case controls. Existing tabs, commands, preferences and battle choices remain available.

**Events** places compact Challenge / Clash / Melee dropdowns directly beneath Rumble, beside Siege, above the separate activity pane. The controls remain scrollable at small sizes. Drag the divider above Activity to resize the log; the controls cannot push it out of view. Activity panels also have **Open larger log**, a resizable live window with a **Follow latest** switch.

**Deck builder** automatically loads owned cards, character/BGE choices and the selected saved slot into the draft when opened. Choosing another slot loads its name and draft. Loading is read-only and never saves automatically. Use **Load / refresh decks & cards** to refresh, choose a saved slot, type its name and click **Rename saved deck** to rename it in the game and refresh every battle selector. Build a **Balanced recommendation**, **One character + items**, **BGE / trait combos**, or **Characters only** draft; choose 25–35 cards, minimum rarity and an optional PC count. BGE matching checks the combo result, and researched combos are required by default. Suggestions use current owned-card stats and recipe coverage, not a battle simulation. The owned pool shows its first 500 matching entries; search narrows the full pool. Double-click a card to add it or remove selected draft cards. **Load slot into draft** supports manual editing. **Save draft to selected slot** replaces that slot's cards only after reviewing the draft, retains its hero/name, backs up the old deck and verifies the write. Changed slots, missing/duplicate cards and uncertain outcomes stop without replay. Previewing spends nothing. A read-only live check generated unique 25-card balanced and single-character drafts without any deck edits.

The **Command Center** provides 114 local commands, including handlers for all 93 observed Bender command names. It uses your own computer and account; Discord and Bender's host are unnecessary. Name coverage does not mean every Bender option or server action has been verified: the parity document makes those limits explicit.

**Automation** saves serial routines, repeats them while Commander is open, stops on errors, and shows local subscription/feed changes. Saved routines start disarmed. Resource spending and destructive actions show their limits before you run them. Stop All also stops the command/routine worker between requests and battles.

**Research** previews and queues every matching recipe from your owned cards. Select input tiers, either/both matching, total speedup hours and an inventory reserve. Start/Resume keeps the saved budget; New Queue applies changed settings. Regular chambers collect completed research and use available speedups within the total budget while the app is open. Real global ad benefits are maintained automatically. **WATCH RESEARCH AD** in Tools, or `research-ad` in Command Center, automatically opens Research from the game home screen, the native TV chamber, its blue timer button and the research Ad Boost prompt, then plays the real Watch ad and uses its completed-ad Close control. No calibration is needed. A running task's ad benefit requires fresh view credit and a lower absolute end time for that exact pair/chamber/task; an uncertain result stops without replay. Two verified automatic ads each reduced the same Mythic task by exactly 45 minutes without gems or speedup items; the second completed the entire route from home. Automatic input-card selection for an empty ad chamber remains pending and must verify both card IDs. A separate controlled research test completed Ae-Rogu-bics using exactly one speedup hour.

To spend your entire speedup inventory, select **Use all available speedups (no reserve)**, choose the desired input tiers and combo limit, then click **NEW QUEUE**. The checkbox overrides the numeric hour budget and reserve; it is off by default. Numeric budgets/reserves also accept up to 1,000,000 hours. Research still needs matching unfinished recipes and an available chamber, and Commander must remain open.

**CHECK SAVED ACTION** checks an uncertain research request using fresh game state without starting, collecting, speeding up or watching an ad. New Queue performs this check before replacing an older queue, even when you changed its settings. If a speedup's target pair is already researched but later inventory changes prevent exact spending verification, its old request is archived without replay and its hours remain explicitly unverified. An action whose target still cannot be established remains blocked.

Research now retries interrupted account/catalog reads with cancellable waits, then schedules up to three delayed reconnect attempts while automatic Research is armed. An interrupted start/speedup/collect is checked from fresh state before any further action; it is never resent merely because the reply timed out. The active run retains its original settings and New Queue/Resume intent across reconnects. Pause/Stop cancels retries; persistent connection failure eventually pauses. Research gets a dedicated 45-second request timeout, and an already verified active boost no longer causes a redundant account download.

**Automation profiles** include the protected Best Daily preset and your own named routines. Best Daily previews current quest requirements, claims explicitly available monthly/weekly login rewards, purchases only remaining Basic Packs within its Nixon budget, completes required Arena battles, handles available events within a global battle limit, advances a separate research queue, and claims rewards. Played-combo goals require a verified researched pair in the active deck. Quest claims re-read current eligibility and pending item choices after each claim so newly unlocked aggregate Daily rewards can be collected safely. It reports skipped or unsupported tasks explicitly. A controlled live Daily run completed all eight exposed goals using three upgrades, three Basic Packs and ten Arena battles, including the matching Adult Bobby requirement. All profiles open disarmed; no automation runs while the app is closed.

Swole, Challenge, Clash and Melee use the direct API with fresh signatures on both starts and moves, including game-AI skip. Earlier unsigned moves could return a winner without awarding challenge rewards or score progress. Controlled live checks now advanced Swole from 92 → 93 → 94, including a fight through the repaired production runner. Swole logs the requested floor and fresh saved score after each fight, pauses if a win does not advance the score/floor, and preserves only remaining fights. Normal starts need no fight capture, manual game initialization or signing-helper window. Arena and Rumble keep their established transport and battle logic. Siege uses the signed enemy-slot request and signed moves after an accepted start; live Siege validation remains pending availability.

On October 8, renewed Swole start rejection was traced to the official game build changing to **1.182.0**. Commander now checks the public launcher for a verified client profile, caches only public version fields for under one hour, and keeps that profile with each accepted battle. An unverified future build pauses combat before a resource request. One controlled battle at floor 104 was accepted and completed as a loss: tickets went **8 → 7**, with score/floor unchanged at 104. No new win or score advance is claimed by that check.

**Character first (Melee only)** is an optional checkbox in Events, off by default and saved immediately. Enable it before starting a character Melee to open a character lane, then add the item to complete an available combo. Combo completion still has priority over opening another lane, and the chosen Battle logic keeps its existing tie-breakers. The runner checks the fresh event name before each fight, so the preference does not change Clash, Challenge, Arena, Rumble or Swole. Command Center/custom routines expose the same option as `melee_character_first=true` for `play mode=melee`; game-AI skip must be off. Best Daily retains its established strategy. No additional live tickets were spent to implement or verify this option.

**Adventure** adds **Complete islands, then farm** with a **100% mastery** goal. **SCAN ISLANDS** previews fresh server progress without starting a fight. The runner completes unfinished stages in island order, includes locked stages in the completion requirement, and rescans after every battle. It returns to your saved default farm mission only after all stages in the active tracks meet the selected goal. **Stage completion** is an optional one-win goal; **100% mastery** uses the game's twelve-step mastery progress, including normalized boss progress. Native campaign membership also restores the event-island stage dropdowns.

Set Battle limit to **0** for no fight-count limit. Keep energy is still respected using each stage's fresh energy cost. With **Continuous monitor** enabled, Commander waits for sufficient energy or an island unlock and resumes while the app remains open. Stop finishes an already charged battle and verifies its progress before stopping; uncertain requests remain recorded locally and are not replayed. A controlled Halloween run used **175 of the provided 176 energy**: Costume Party reached **100%**, The Mummies reached **94.4%** with two wins remaining, and The Witching Hour unlocked. The run stopped with one energy left and did not resume default farming prematurely. The eventual return to default farming is covered offline; the full Halloween route has not yet finished live.

Adventure now recovers an old accepted farming attempt when its stage is already mastered, fresh full game state advertises no resumable battle, and the request is no longer recent. Its old outcome stays unknown in a bounded local history; no win/loss is invented and no old request is replayed. Unaccepted starts, incomplete island progress, active/unknown battles and contradictory state still pause. Pause/error reasons stay visible instead of being followed by a misleading “farm complete” message.

**Game / Ads** opens the dedicated real game browser inside a compact panel in Commander, with Larger and Hide controls. Its existing login/profile is retained. Startup handling verifies pending rewards and dismisses supported ordinary reward/offer displays before ad navigation. A cold launch through Play Now and the startup sale offer reached the game home screen inside the panel. Unknown popups stop safely; the Quest Complete display route still needs a live encounter for verification.

Live CM-shop offers and current event Adventure missions are read from authoritative account catalogs. Choice rewards use Rogu → other Characters → Items / Power Cards. Golden Packs remain real single purchases with adaptive pacing; mouse-free rewarded ads still use legitimate playback and completion verification.

Ad startup navigation now supports the exact public 1.183 build as well as prior verified builds. Previously, the combat profile accepted 1.183 while the popup guard rejected it before real ad playback. The new popup layouts and eleven ordinary navigation handlers were verified offline against the official public assets. Unknown builds and paid/foreign actions remain blocked. Live ad completion after this update has not yet been verified. A Discord connection alone cannot automatically invoke Bender’s `/user-ad` slash command; no unsupported user-token relay or fabricated ad completion is implemented.

## CM Reviews

The desktop **CM Reviews** tab uses current Animation Throwdown static/account data to generate a deterministic 0–10 practical Combo Mastery review. It is inspired by the long-running community review framework—current strength, skill package, BGE relevance, PC usefulness, power creep and spending value—without copying old scores or prose as if they were permanently correct.

The optional Discord companion uses the exact same engine. See `DISCORD_CM_BOT_SETUP.md` or click **BOT SETUP** in the CM Reviews tab.

Community lookup now uses public Reddit RSS with paced requests and JSON fallback, dated ratings, section boundaries, reviewer deduplication, and separate matched/no-match/unavailable/stale states. Recent CM/BGE image posts are also searched through their review comments, and punctuation aliases reuse consistent cache entries. A stale or unavailable refresh removes any previous community score adjustment. A large disagreement with the current card-power score is shown alongside it without replacing that score. Anonymous provider rate limits can still prevent a live lookup.

Research mapping now checks Pause/Stop while building a large queue. The table renders in small batches and shows at most 5,000 rows while the saved queue retains all selected pairs. Tk cleanup stays on the main thread; closing waits for active research to settle. Safe crash diagnostics record stack locations without request payloads or exception data. Controlled desktop Preview → Pause, Preview → Stop All and Start/Resume → Stop All kept the app open; the existing queue and speedup budget were preserved.

Arena has an optional **Bypass 30-turn cutoff** checkbox for combo events. It defaults off, retains Pause/Stop, and continues until the game returns an outcome. An unknown continuing battle state stops without repeating the move. Best Daily explicitly keeps this option off for its Arena and event steps.

Local guild reports and defense plans support HTML/CSV/JSON workflows. Card maps support SVG/HTML/PNG/JPEG and three layouts, using exact selected-level stats. Deck swap/restore validates both sides, keeps backups and verifies each write from fresh state.

The current source passes **1,339 offline regression tests**, including 28 new deck-workshop/log/selector checks, 30 application-updater/privacy checks and 135 Adventure checks for island scanning, native progress, completion sequencing, energy limits, capped-farm recovery, retained unknown outcomes, changed journal records, pause/error messages, Stop, GUI controls and saved farming preferences. Coverage also includes 34 Research controls/recovery checks, Melee character-first sequencing/targeting, saved preferences and mode isolation, signed challenge moves, Swole score verification and remaining-fight preservation, embedded browser ownership/cleanup, startup popup guards, large research cancellation, daily automation, research ads, guild reports, deck safety and CM lookup fixes.
