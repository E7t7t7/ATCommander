# AT Commander 1.7.27 — restart-aware updates

An update check previously compared GitHub with the files on disk. An app left
open while those files changed could therefore say “up to date” while retaining
older code in memory. All recent fixes also shared the 1.7.26 label, making the
running interface difficult to identify.

- Startup captures a fingerprint of the public runtime sources. A check that
  finds current disk files but a different running snapshot now requires a
  restart instead of reporting that the running app is current.
- A downloaded or already-installed update changes the button to **Restart to
  apply**. Clicking it uses the normal Stop/close path, waits for active work,
  closes the game browser and releases the application lock before reopening
  through the normal starter. No battle, purchase or research request is replayed.
- Replaced Python modules have only their own generated bytecode caches removed.
  This also protects against same-timestamp/same-size stale caches. Unrelated
  caches and user data are preserved; rollback still restores previous sources.
- The window title and startup update bar identify **1.7.27**. The package and
  generated manifest use the same version. Existing installation folders and
  portable ZIP roots may still be named ATCommander_1.7.26; those folder names
  do not identify the running release.
- Includes the compact Challenges/Clash/Melee controls beneath Rumble, the visible
  activity pane, automatic workshop loading and the verified 1.183 ad-startup
  profile. This release makes no additional live ad-completion claim.

All **1,348 offline tests** pass. New checks cover disk-current/running-old
updates, the Restart action, waiting for clean shutdown and lock release,
ordinary exits, failed startup, direct hidden starter launch and stale bytecode.

For the first upgrade from 1.7.26, use its update button, close Commander fully,
then reopen **AT Commander.exe**. Confirm **1.7.27** in the window title. The new
Restart button is available for subsequent updates; an already-open old version
cannot acquire the new controls until it is restarted.
